# OrcasGames
## Description
Aplikasi ini bertujuan untuk memudahkan pengguna dalam membeli, mengelola, dan menemukan game sesuai dengan preferensi mereka. Dengan antarmuka berbasis Jetpack Compose, pengguna dapat menjelajahi katalog game yang tersedia.
## How to Run the Application

Follow these steps to set up and run the application:

1. **Clone the repository**  
   Run the following command to clone the repository to your local machine:
   ```bash
   git clone <URL_REPOSITORY>
2. **Navigate to project directory**
   ```bash
   cd project-name
3. **Run the app**
   
   On Linux:
   ```bash
   ./gradelw run
   ```
  
   On Windows:
   ```bash
   gradlew.bat run
   ```
## Features
### 🔄 Integrasi Firestore & Room & Retrofit
-Implementasi Room(Local Storage) yang dibarengin dengan Firestore dan penggunaan API Rawg menggunakan Retrofit
### 🌍 Variasi Games
-Mengambil data games dari Rawg API
### 🛒 Pembelian & Transaksi
- **Checkout belum tersedia (akan ada di update selanjutnya).**
### 🎮 Achievement & Theme
- **Toggle Tema**: Beralih antara mode terang dan gelap.
- **Achievement**: Dapatkan pencapaian saat bermain dan membeli game.
### ⚙️ Pengaturan
- Sesuaikan preferensi pengguna dalam menu pengaturan.
## 🎨 Desain UI Modern
- **Swipeable Card** untuk interaksi lebih intuitif.
- **Interaktif** untuk membuka semua menu yang tersedia anda harus "login" terlebih dahulu
- **Modern Looks** UI terlihat modern.
